# 就職活動用ポートフォリオ（サンプル）

研究、開発、組織活動を一つのページで紹介する静的Webサイトです。現時点の氏名・所属・活動内容はすべて仮の内容です。

## ファイル

- `index.html`：文章とページ構造
- `styles.css`：色、文字、余白、画面幅に応じたレイアウト
- `DESIGN_NOTES.md`：参考にした実在のWebページと設計資料

## 手元で見る・編集する

`index.html` をブラウザで開けば表示できます。編集には VS Code などのテキストエディタを使えます。外部ライブラリやビルド操作は不要です。

## 実際の応募に使う前に

1. 氏名・所属と研究テーマを実情報に置き換える。
2. 各事例に自分の担当、結果、公開可能な資料を記載する。
3. 資格・受賞歴と外部リンクを確認する。
4. ページ上部のサンプル表示を削除する。
5. スマートフォンで読み直し、リンク先を確認してから公開する。

ESに貼るには、GitHub Pagesなどで一般にアクセスできるURLを用意してください。`localhost` は自分の端末での確認用です。
